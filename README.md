# پروژه‌های وایب کدینگ

این مخزن برای نگهداری چند پروژه مستقل ساخته شده است. هر پروژه کد، تنظیمات و راهنمای خودش را در یک پوشه جداگانه دارد.

## پروژه‌ها

- [میزان](./mizan/) — سامانه فارسی مدیریت سوپرمارکت، ساخته‌شده با Next.js و Supabase.

برای اجرای میزان:

```bash
cd mizan
pnpm install
pnpm dev
```

راهنمای کامل راه‌اندازی و استقرار در [README پروژه میزان](./mizan/README.md) آمده است. برای استقرار این پروژه از روی این مخزن، پوشه ریشه برنامه را `mizan` انتخاب کنید.
